# Pixel Art Uniformity & Art Direction Rule

When creating, editing, or generating pixel art sprites (pets, bosses, animations, icons) for Omnia:
1. **Unified Aesthetic:** Always follow `PIXEL_ART_GUIDE.md`. Pets and Bosses MUST belong to the exact same 16-bit JRPG retro game style (SNES/GBA style like Chrono Trigger or Pokémon GBA).
2. **No Mixels:** Bosses must NOT use high-density micro-pixels. They must use the same chunky square pixel grid (~48x48 / 64x64 logical grid upscaled cleanly to 288x288) as the mascots.
3. **Outlines:** All sprites must have a 1-2px solid dark pixel outline to contrast cleanly on all light and dark themes.
4. **Color Palettes:** Cel-shaded blocks only, limited retro palette, transparent alpha PNG with zero white fringe.
