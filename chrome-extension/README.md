# Omnia Blocker (Chrome Extension)

Esta extensão bloqueia distrações (Instagram, Twitter/X, TikTok, Facebook) **automaticamente** assim que você clica em "Iniciar" no Modo Foco (Pomodoro) do Omnia, e libera tudo de volta quando a sessão termina ou é pausada.

## Como instalar

1. Abra o Chrome e acesse `chrome://extensions/`
2. Ative o "Modo do desenvolvedor" (Developer mode) no canto superior direito.
3. Clique em "Carregar sem compactação" (Load unpacked).
4. Selecione a pasta `chrome-extension` que está dentro do projeto `Minha-vida-em-um-app`.
5. Pronto! Agora abra o Omnia no navegador e teste o Modo Foco.
